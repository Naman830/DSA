Subarray is: A continuous part of an array

Continuous means:
elements must stay together
no skipping allowed

Possible subarrays:

[1]
[2]
[3]

[1,2]
[2,3]
[3,4]

[1,2,3]
[2,3,4]

[1,2,3,4,5]


Formula of Total Subarrays
If array size = N
Then total subarrays: N(N+1)/2
